# QueenAtlantis-Yacht : Anchor of Luxury & Technology

Welcome to the technical showcase of the [Queen Atlantis Yacht](https://queenatlantis.com) project. This repository serves as a portfolio piece demonstrating a complete end-to-end digital transformation for a real-world luxury yacht business.

### 🏆 Technical Highlights & Engineering Success

As the lead developer, the goal was to blend premium aesthetics with automated functionality. While the frontend was crafted with **WordPress** and **Elementor** for pixel-perfect design, the true engineering success lies in the backend architecture:

- **Dynamic Availability Engine**: A fully custom integration with the **Google Calendar API**.
- **Automated Data Parsing**: The system intelligently reads calendar event tags (`booked`, `Fet.` for Fethiye, `Bod.` for Bodrum, `Göc.` for Göcek) and renders them in real-time with specific UI colors, removing the need for manual CMS updates by the client.
- **Premium Digital Assets**: Delivery of the high-end `eng_queenatlantis_last.pdf` catalog, showcasing multidisciplinary capability from code to design.
